You can use TianGong LCA directly in your browser. If you need terminal operations, AI assistance, or local file processing, choose a tool by task. You do not need to install all of them.

| I want to… | Start here |
| --- | --- |
| Install a command-line client, sign in, and query the platform | [CLI user guide](/en/docs/integration/cli/) |
| Have an AI follow clear search or data workflows | [Agent Skills guide](/en/docs/integration/skills/) |
| Validate and convert packages locally without platform sign-in | [Local tidas tools](/en/docs/integration/tidas/) |

MCP is another way to connect tools to a compatible client. If you already use one, choose a local or remote connection below. MCP is not a prerequisite for the CLI or Skills introduction.
