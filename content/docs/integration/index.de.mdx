TianGong LCA lässt sich direkt im Browser nutzen. Für Terminalaufgaben, KI-Unterstützung oder lokale Dateien wählen Sie ein passendes Werkzeug. Sie müssen nicht alle installieren.

| Ich möchte … | Hier beginnen |
| --- | --- |
| CLI installieren, anmelden und Plattformdaten abfragen | [CLI-Benutzerhandbuch](/de/docs/integration/cli/) |
| Eine KI klare Such- oder Datenabläufe ausführen lassen | [Agent-Skills-Handbuch](/de/docs/integration/skills/) |
| Pakete lokal ohne Plattformanmeldung prüfen und konvertieren | [Lokale tidas-Werkzeuge](/de/docs/integration/tidas/) |

MCP ist eine weitere Anbindung an kompatible Clients. Falls Sie bereits einen solchen Client verwenden, wählen Sie unten lokal oder remote. MCP ist keine Voraussetzung für den CLI- oder Skills-Einstieg.
