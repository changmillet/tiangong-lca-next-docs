你可以直接在网页中使用 TianGong LCA。需要终端操作、AI 辅助或本地文件处理时，再根据任务选择下面的工具，不必把它们全部安装。

| 我想做什么 | 从这里开始 |
| --- | --- |
| 安装命令行、登录并查询平台数据 | [CLI 用户指南](/zh/docs/integration/cli/) |
| 让 AI 按清晰步骤检索或处理数据 | [Agent Skills 指南](/zh/docs/integration/skills/) |
| 不登录平台，在本地验证与转换数据包 | [本地 tidas 工具](/zh/docs/integration/tidas/) |

MCP 是把工具接入支持该协议的客户端的另一种方式。已有 MCP 客户端时，可按下方目录选择本地或远程连接；它不是 CLI 或 Skills 入门的前置条件。
